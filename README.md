# SALTLINE — a three.js tactical FPS

A Counter-Strike-style tactical FPS in the browser: you lead the Jackals, five
against five, planting a breach charge at one of two sites in a dusk salt
refinery — or the Wardens stop you. Full round economy with a buy menu, five
weapons, three grenade types, headshot multipliers, recoil and spread that
punish movement, and bots that run routes, hold angles, rotate on radio calls,
plant and defuse.

No build step, no dependencies, nothing over the network: three.js is vendored
under `game/vendor/`, all textures are canvas-generated and all sound is
WebAudio-synthesised.

## Run it

```sh
node serve.ts        # then open http://localhost:8080
```
